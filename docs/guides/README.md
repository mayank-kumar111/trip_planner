# User & Developer Guides

## Executive view
This directory separates product usage from engineering onboarding so technical and non-technical readers can learn the system without reading source code first.

## Documents
- `DEVELOPER_ONBOARDING.md` — setup, architecture, change workflow, and verification.
- `USER_ADMIN_GUIDE.md` — traveler/admin-facing product behavior and operational expectations.

## Audience
Developers should begin with `DEVELOPER_ONBOARDING.md`. Product, support, and non-technical stakeholders should begin with `USER_ADMIN_GUIDE.md`.
